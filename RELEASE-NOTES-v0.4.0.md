# EarthBound Companion v0.4.0 — private preview

This is the first friend-ready Windows x64 test package.

## Setup

1. Download and extract `EarthBound-Companion-Tester-v0.4.0.zip`.
2. Run `EarthBound Companion.exe`.
3. Select your own legally obtained clean EarthBound (USA) ROM.
4. Leave the MSU option enabled for the complete soundtrack experience.

The package contains no ROM, extracted asset pack, save, screenshot or PCM soundtrack payload. The selected ROM is verified, read locally and never modified or uploaded.

## Highlights

- Native compiled Windows gameplay with a self-contained settings launcher.
- 1080p, 1440p, 4K and 3440×1440 output; 4:3, 16:9 and 21:9.
- Crisp, Scale2x and smooth rendering plus optional depth, color and scanline effects.
- Full controller and keyboard rebinding, analog movement and hotplug.
- Native MSU playback with 164-track download/repair and integrity verification.
- Sprint, fast dialogue, fast-forward, five quick-save banks and save recovery.
- Story Shuffle v2 randomizer with deterministic recipes, isolated saves and conservative original-story progression guards.
