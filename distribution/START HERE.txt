EARTHBOUND COMPANION — PRIVATE TEST BUILD
=========================================

1. Extract this entire ZIP to a normal folder. Do not run it from inside the ZIP.
2. Double-click "EarthBound Companion.exe".
3. Choose your own clean EarthBound (USA) .sfc or .smc ROM.
4. Leave the complete MSU soundtrack option checked for the full audio experience.
5. Wait for setup to finish, then click Play EarthBound.

The ROM is verified and read locally. It is never changed, copied into this folder,
or uploaded. The soundtrack download is about 1.25 GB. Setup verifies every track
and can resume later through Audio > Install / repair soundtrack.

The default Enhanced preset enables 1080p borderless output, widescreen scenery,
Scale2x, color grading, depth effects, faster dialogue, sprinting and MSU music.
Display, audio, gameplay and controls are all adjustable.

Story Shuffle is under Solo Play > Randomized adventure. It protects the original
story's required quest and trade items. Each seed has separate saves. Read
RANDOMIZER.md before testing it.

This is a private test build of a community native reimplementation. A complete
playthrough has not yet been verified. Keep normal phone saves for long-term play,
and send the UserData/game.log file with any bug report.

the current upstream licensing limitation.
