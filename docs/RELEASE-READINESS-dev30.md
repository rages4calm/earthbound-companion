# Dev.30 release readiness

The user completed a Redux campaign through Giygas and credits and reported remembered side activities. Stats/equipment were boosted for final testing. The resulting playtest fixes are shipped in dev.30. This is one completed user-reported campaign; full compatibility and randomized campaigns are not certified.

A fresh source tree made from the pinned native foundation, exact public patch and pinned Tamp submodule compiled successfully without a ROM, extracted JSON or a game pack. It uses explicitly supplied local compiler/SDL tools; automatic toolchain provisioning is a separate scope. The fresh binary and the exact shipping binary both pass the bounded runtime regressions.

A fresh extraction of the actual dev.30 release ZIP performed self-contained first-run setup with the owner's headered ROM, pinned online Redux source and no Python on PATH. Both expected packs were rebuilt. One deliberately corrupt music track and a stale partial were repaired by the production downloader; the other 163 tracks were reused through private hardlinks and all 164 were independently checked. Story/seed opening, ordinary house interaction/movement, profile isolation and copied checkpoint recovery passed. Native audio checks cover eight Sound Stone transitions, one SPC effect, missing-track fallback, 125 loop boundaries and 39 one-shot endings. They do not replace listening to every story transition.

The repeatable regression command runs 76 checks when supplied both shipping and clean-source players: 64 runtime checks plus 12 prepared scenario runs across both editions. Scenarios include every credits photograph, PSI projection, Lumine text playback, blank staging canvases, Redux extended equipment comparisons, prepared Giygas sprite repacking and all seven prayer callbacks per edition. Original has its original two-stat equipment display, so the Redux extended-preview pixel contract is explicitly inapplicable there; the shared blank-canvas regression still executes. The initially reused Redux preview fixture failed on Original because its layout contract differed; this was corrected as a fixture scope error, not reported as a native defect.

PSI projection samples every arrangement change: 34 Original and 68 Redux definitions, two bit depths and three horizontal targets, 612 cases and 16,494 sampled frames. It uses diagnostic white ink to isolate geometry. The Giygas sprite regression checks real group loading and emitted OAM for a poisoned old allocation, both rows and normal/alternate maps. It passes the shipping player and detects the old dev.28 defect. These are prepared render contracts, not all combat outcomes or color parity.

The offscreen presentation matrix checks 45 cases per edition across 1280x720, 1920x1080, 2560x1440, 3840x2160 and 3440x1440, three aspect settings and three filter configurations. It exercises actual SDL presentation using a software/dummy backend and verifies dimensions, capture completeness and nonblank output. Representative captures were reviewed locally. The host has one 1920x1080 display; the matrix does not claim physical ultrawide/4K or GPU-driver testing. Input-remap/deadzone/hotkey/focus tests use simulated sources; actual physical-controller gameplay remains unverified by the automated suite.

The workspace cleanup retains the native dirty tree, canonical public source, current/rollback ZIPs, owner ROM, conversion dependencies, media and current installation. Historical evidence and recovery material are archived locally; disposable staging and build intermediates are removed using checked literal PowerShell paths. Post-cleanup canonical launcher publishing, ZIP manifest/CRC checks, isolated profile tests and packaged native PC selftests pass. The rebuilt private smoke launcher has its own identity; the published ZIP remains unchanged. Package builds now require an explicit native candidate and use the canonical public launcher source, preventing silent selection of an older default binary. This work does not edit personal saves or change gameplay binaries.

## Reproduce

Use `scripts/release_regressions.py --help` with matching frozen build/runtime inputs and local packs, a pinned Redux project and a new private scratch directory. `scripts/clean_public_source_qa.py --help` verifies source composition and fresh compilation. `scripts/presentation_matrix_qa.py --help` runs offscreen presentation; its optional checkpoint is copied. `scripts/verify_redux_package_dev18.py` remains the complete self-contained setup verifier and accepts the current ZIP contract. All outputs containing packs, checkpoints, frames, generated ROMs or music stay private.

Public receipts: [clean source](../validation/public-clean-source-dev30.json), [clean package](../validation/clean-package-dev30.json), [release regressions](../validation/release-regressions-dev30.json), [presentation matrix](../validation/presentation-matrix-dev30.json), [scenario details](../validation/presentation-regressions-dev30.json), [post-cleanup packaging](../validation/post-cleanup-package-dev30.json), and [workspace cleanup](../validation/workspace-cleanup-dev30.json).

Remaining work is specific: untested conversion branches and natural quest/photo/cast choices, full randomized progression, broader physical hardware and listening. Keep these limits separate from the completed user playthrough and passing prepared regressions.
