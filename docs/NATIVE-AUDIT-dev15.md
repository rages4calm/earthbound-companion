# Native audit checkpoint: dev.15

This checkpoint continues the [dev.14 audit](NATIVE-AUDIT.md). It adds confirmed native corrections, original-machine comparisons, and prepared production scenarios. A complete story or randomized playthrough remains unverified. The pinned Redux source is still `897d00833f4a08a0a92f106abf631629a6a6a041`; the asset packs and save namespaces are unchanged.

## Corrected behavior

- **Cold battle dependencies:** NPC maximum HP, destroyed Teddy Bear replacement, consolation selection during battle PREP, and NPC target interception now bind their required tables at the actual consumer. Loading mid-action no longer depends on replaying battle entry. Original and Redux tests reproduce the previous failures and pass after the correction.
- **Enemy summoning:** membership is checked against the full source battle group, including enemy types with initial count zero. Their battle art is preloaded as the original routine requires. These entries represent summonable enemies. All 484 groups in each pack have valid pointers, terminators, enemy/art records and capacity bounds; the four-allocation guard remains. Actual bound/cold summon and sprite-layout tests cover both editions.
- **Special encounters:** cold scene transitions resolve the requested backgrounds instead of falling back to background zero. Redux portrait state is cleared at the exact prayer/Pokey source stages. Poo's entrance suspends portraits until its text returns, then resumes them at the correct source hook. The existing 12-byte state layout is retained, including older active-0/1 checkpoints. Prepared-state fixes and rendered checks do not establish a complete Giygas encounter or ending.
- **Conditional map music:** the source's `BLTEQ` macro uses unsigned `BCC`/`BEQ`; the native selector had treated it as signed. The correction restores the low-flag conditions in the boarding school, department store and Ness's home. Full original and pinned Redux CPU execution verifies selection; cold native save/load tests preserve all 1,023 flags. These are track-selection checks, not a listening audit.
- **Point collision coordinates:** the single-point helper now preserves wrapped 16-bit coordinates and logical shifts when recording ladder tiles. Independent comparisons reproduce the former high-bit discrepancy. This was not demonstrated as a normal-story crash.
- **Terrain and Skip Sandwich movement:** the native modifier calculation retained fractional speed bits that the source discards before multiplication. Exact signed rounding and wrapped position addition now match untouched original H/V routines. This includes the source's different positive/negative diagonal rounding. The collision guard and sprint addition remain intact; sprint regression expectations now use recorded original-machine deltas.
- **Repeated Offense Up:** Redux adds its buff to the current offense, with a wrapped doubling and logical shift. The old native code used base offense for that increment. Real dispatch and untouched Original/pinned Redux CPU comparisons verify the correction; Original's separate formula is retained.
- **Dialogue audio commands:** music changes now update both map-track fields in the source order. A zero sound operand resolves argument memory before queuing the effect. Both literal and dynamic controls run through the real command dispatcher with the actual APU initialized. This does not establish exact meter/yield timing or explain every shopping sound report.
- **Jeff's repair RNG:** eligible broken items now consume the serialized game generator rather than a separate C-library generator. All packed broken records have warm and fresh-process repair-chance controls in both profiles. Other legacy C-library RNG consumers and the complete call timeline remain under audit.
