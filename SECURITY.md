# Security and responsible reports

Please report security problems through GitHub’s private vulnerability-reporting feature when available. Do not include ROMs, extracted game data, save files, access tokens, private keys or personal paths in a report.

For ordinary crashes and gameplay bugs, open an issue with the Companion version, Windows version, reproduction steps and a redacted `UserData/game.log`. Attach a normal phone save only after confirming that the repository owner requests it and that sharing it is appropriate.
